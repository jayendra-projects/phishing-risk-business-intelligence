## Project Overview

This project developed a multi-audience Power BI reporting solution to analyse simulated phishing campaign performance, employee security awareness and organisational vulnerability.

Three stakeholder-specific dashboards were designed for:

- Phishing Campaign Manager
- HR Manager
- Individual Users

The solution translated different stakeholder information needs into targeted KPIs and visualisations covering campaign effectiveness, phishing-test performance, employee training, awareness levels, regional exposure, device usage and user response behaviour.

The analytical workflow followed:

**Stakeholder Needs → Business Rules → KPI Definition → Data Analysis → Power BI Dashboard Design → Risk Identification → Business Recommendations**
